# Roadmap

## Now

- Keep the built-in Claude, Codex, DeepSeek, and GLM profiles current.
- Expand source-audited Three.js and Twigl prompt coverage without sacrificing provenance.
- Publish polished official examples with compact redacted evidence.

## Next

- Add a static filterable prompt and result gallery generated from the same repository data.
- Add machine-readable community result manifests and a validator.
- Improve hardware and runner disclosure in exported captions.
- Add optional rubric-based human review without replacing the visual evidence.

## Later

- Skillflow.net result pages that receive only the final comparison video.
- Cross-machine deterministic capture studies.
- Broader runner adapters when providers expose stable, documented integration surfaces.

The roadmap is directional, not a promise. Open an issue before implementing a new runner, method, or public ranking model so fairness and maintenance costs can be discussed first.
