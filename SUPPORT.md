# Support

Use GitHub Discussions for setup questions, methodology discussion, showcase posts, and ideas. Use the structured issue forms for reproducible bugs, model profile requests, and prompt candidates. Use private vulnerability reporting for credentials or security-sensitive problems.

Before asking for help, run:

```bash
npm run benchmark -- doctor
npm run check:public
```

Share only sanitized output. Never post keys, tokens, private endpoints, raw login files, or unreviewed `runs/` contents.
